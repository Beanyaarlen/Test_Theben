KENALI PRODUK

Informasi iONprime PB KNX

  • Switching, dimming, blinds, value sender, dan scenes melalui bus coupler terintegrasi.
  • LED RGB per tombol untuk status/operasi; brightness dapat diatur atau mengikuti cahaya sekitar.
  • Sensor suhu, kelembapan, kecerahan, proximity, dan IAQ berbasis nilai CO₂.
  • Dua threshold yang dapat dikonfigurasi untuk masing-masing suhu dan kelembapan.
  • Temperature controller terintegrasi untuk pengaturan mode dan temperatur.
  • Empat kanal logic terpisah: AND / OR / XOR, dengan hingga 4 input objects.
  • Satu base unit untuk rocker tunggal, ganda, atau empat; tujuh pilihan material/warna.
  • Dust cover tetap mendukung tombol dan LED selama pekerjaan; ganti dengan rocker setelah finishing. Pemasangan dapat memakai sekrup plastik yang disertakan untuk pengamanan.
